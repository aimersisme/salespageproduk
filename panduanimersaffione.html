1. Persiapan Sebelum Instalasi

Jangan mulai instalasi sebelum tiga akun berikut siap. Ini akan mengurangi error di tengah proses.

SupabaseDatabase, login owner, dan penyimpanan gambar.
GitHubTempat menyimpan source code iMers AffioNe.
VercelTempat menjalankan website secara online.
Yang paling idealDaftar GitHub terlebih dahulu, lalu daftar/login ke Vercel menggunakan akun GitHub yang sama. Dengan begitu proses import repository nanti jauh lebih mudah.

Checklist sebelum lanjut

  • Bisa login ke dashboard Supabase.
  • Bisa login ke GitHub.
  • Bisa login ke Vercel.
  • Di Vercel, akun GitHub sudah tersambung.
  • Siapkan email dan password yang akan dipakai sebagai akun owner/admin iMers AffioNe.

2. Download iMers AffioNe dari Member Area

Gunakan file release terbaru yang tersedia di Member Area.

1

Login ke Member Area

Masuk menggunakan akun pembelian/lisensi Anda, lalu cari produk iMers AffioNe.

2

Download file FULL ZIP

Unduh file dengan nama kurang lebih seperti:

iMers-AffioNe-vX.X.X-FULL.zip

Gunakan versi paling baru yang tersedia.

3

Extract ZIP

Klik kanan file ZIP → Extract All / Extract Here. Jangan upload ZIP mentah ke GitHub.

Jangan hapus folder SupabaseDi dalam source terdapat fresh installer SQL yang diperlukan untuk menyiapkan database.

File penting yang akan dipakai

FileFungsi
supabase/install/00_FULL_FRESH_INSTALL.sqlInstaller database untuk pemasangan baru.
.env.exampleContoh environment variable yang dibutuhkan.
README.md / INSTALLATION.mdCatatan versi dan instalasi tambahan.

3. Membuat Project Supabase

Supabase menangani database, authentication, dan storage media.

1

Create New Project

Dari dashboard Supabase, klik New Project. Pilih organization Anda.

2

Isi project

Contoh nama project: imers-affione. Buat password database yang kuat dan simpan baik-baik. Pilih region terdekat.

3

Tunggu project selesai dibuat

Setelah dashboard project terbuka, jangan lanjut ke GitHub dulu. Kita siapkan database lebih dahulu.

4

Buka SQL Editor

Di sidebar Supabase pilih SQL Editor → New query.

5

Buka fresh installer dari source

Dari folder hasil extract, buka:

supabase/install/00_FULL_FRESH_INSTALL.sql

Copy seluruh isi SQL tersebut.

6

Paste lalu Run

Paste SQL ke SQL Editor lalu klik Run. Tunggu sampai muncul status sukses.

Untuk instalasi baruCukup jalankan fresh installer terbaru. Anda tidak perlu menjalankan migration versi lama satu per satu.

4. Membuat Akun Owner / Admin

iMers AffioNe adalah aplikasi single-owner. Tidak ada pendaftaran publik.

1

Buka Authentication

Di Supabase pilih Authentication → Users.

2

Add User

Buat user baru menggunakan email dan password Anda sendiri.

3

Pastikan email terkonfirmasi

Jika tersedia pilihan auto-confirm / confirm user, pastikan akun dapat langsung login.

4

Matikan public signup

Karena aplikasi hanya untuk 1 owner, buka pengaturan Auth dan nonaktifkan registrasi publik bila masih aktif.

Simpan password ownerPassword ini digunakan untuk masuk ke halaman admin iMers AffioNe setelah website live.

5. Upload Source ke GitHub

Untuk pemula, cara termudah adalah membuat repository baru lalu upload seluruh isi source hasil extract.

1

Buat repository baru

Di GitHub klik New repository. Contoh nama: imers-affione.

2

Pilih Private

Untuk source code berlisensi personal, disarankan membuat repository Private.

3

Upload files

Buka repository → Add file → Upload files. Upload isi folder hasil extract, bukan folder luarnya saja.

Jangan upload file rahasiaJangan pernah upload .env.local, password database, atau Supabase service role key ke GitHub.

Struktur yang benar di root repository

app/ components/ lib/ public/ supabase/ package.json .env.example README.md ...

Kalau yang terlihat justru hanya satu folder seperti iMers-AffioNe-v1.x.x-FULL/, berarti source berada satu tingkat terlalu dalam.

6. Import GitHub ke Vercel

Karena GitHub sudah terhubung ke Vercel, deployment hanya beberapa langkah.

1

Tambah Project

Masuk Vercel → klik Add New → Project.

2

Pilih repository

Cari repository imers-affione, lalu klik Import.

3

Framework

Vercel biasanya otomatis mendeteksi Next.js. Jangan ubah Build Command / Output Directory jika tidak diperlukan.

4

Jangan deploy dulu

Sebelum menekan Deploy, isi Environment Variables Supabase terlebih dahulu.

7. Mengisi Environment Variables

Ini langkah penting agar website Vercel dapat terhubung ke Supabase.

A. Ambil data dari Supabase

Buka pengaturan project Supabase dan cari informasi API project. Yang dibutuhkan adalah:

Project URL Anon / Publishable Key

B. Isi di Vercel

NameValue
NEXT_PUBLIC_SUPABASE_URLIsi dengan Project URL dari Supabase.
NEXT_PUBLIC_SUPABASE_ANON_KEYIsi dengan anon/publishable key project.
NEXT_PUBLIC_SITE_URLBoleh sementara memakai URL Vercel, misalnya https://imers-affione.vercel.app
Jangan gunakan Service Role KeyFrontend iMers AffioNe tidak membutuhkan service role key. Jangan memasukkannya sebagai NEXT_PUBLIC environment variable.
1

Save Environment Variables

Pastikan masing-masing variable tersimpan untuk Production.

2

Deploy

Klik Deploy. Tunggu proses build sampai selesai.

9. Setting Awal Setelah Live

Jangan langsung promosi sebelum melakukan personalisasi berikut.

Tampilan Toko

  • Ganti nama toko dan tagline.
  • Upload logo.
  • Upload banner. Ukuran rekomendasi 1600 × 700 px, minimum 1200 × 525 px.
  • Pilih salah satu preset tema atau gunakan Custom Color.
  • Isi kontak dan sosial media.
  • Isi SEO title dan description.

Kategori

  • Edit/hapus kategori dummy jika tidak dibutuhkan.
  • Buat kategori sesuai niche Anda.
  • Gunakan icon bawaan atau upload icon kategori sendiri.

Produk

  • Semua dummy product dapat diedit atau dihapus.
  • Isi nama produk, harga, harga coret, kategori, deskripsi, dan affiliate URL.
  • Upload foto produk dan foto tambahan.
  • Tambahkan video URL bila ada.
  • Atur CTA per produk, misalnya Beli di Shopee, Cek di TikTok Shop, atau teks lainnya.
  • Publish hanya produk yang siap ditampilkan.
Tidak hanya untuk ShopeeCTA dan marketplace dibuat fleksibel. Anda dapat menggunakan link affiliate dari platform lain selama link tujuan Anda valid.

10. Cara Update ke Versi Baru

Untuk pengguna yang sudah live, jangan menjalankan fresh installer lagi.

Jika release baru menyediakan UPDATE-SQL

  1. Download FULL ZIP versi terbaru dari Member Area.
  2. Buka file UPDATE-SQL-vX.X.X.sql.
  3. Jalankan query tersebut di Supabase SQL Editor.
  4. Extract FULL ZIP baru.
  5. Overwrite source lama di repository GitHub dengan source terbaru.
  6. Commit perubahan.
  7. Vercel akan redeploy otomatis.
Fresh installer hanya untuk instalasi baruFile 00_FULL_FRESH_INSTALL.sql tidak digunakan untuk upgrade database yang sudah berisi data.

Sebelum update

  • Simpan backup data penting.
  • Pastikan memakai versi update yang urut.
  • Baca RELEASE-NOTES jika tersedia.

Troubleshooting

Beberapa masalah yang umum ditemui pemula.

Homepage menampilkan “Toko affiliate belum diaktifkan”

Pastikan fresh installer SQL berhasil, akun owner sudah dibuat, lalu login ke dashboard dan lengkapi Tampilan Toko.

Error “permission denied for table stores”

Gunakan UPDATE-SQL/hotfix versi terbaru dari Member Area karena schema lama mungkin belum memiliki privilege/policy yang dibutuhkan.

Login gagal padahal email/password benar

Periksa user pada Supabase Authentication → Users. Pastikan user aktif/confirmed dan environment variable Vercel menunjuk ke project Supabase yang sama.

Perubahan GitHub belum tampil di website

Buka Vercel → Deployments dan pastikan deployment terbaru berhasil. Bila perlu lakukan Redeploy.

Build Vercel gagal

Baca error log Vercel. Pastikan semua file source di root repository, package.json tersedia, dan environment variables telah diisi dengan benar.

Gambar/banner tidak dapat di-upload

Pastikan fresh installer/storage policy versi terbaru telah dijalankan dan Anda sedang login sebagai owner.

FAQ Pemula

Apakah wajib membeli hosting?

Tidak. iMers AffioNe dapat dijalankan menggunakan free tier Vercel.

Apakah wajib membeli domain?

Tidak. Vercel memberi URL gratis. Custom domain hanya opsional jika Anda ingin branding sendiri.

Apakah harus bisa coding?

Untuk proses instalasi dasar tidak. Anda cukup mengikuti urutan Supabase → GitHub → Vercel dalam panduan ini.

Bisa digunakan untuk marketplace selain Shopee?

Bisa. Produk menyimpan affiliate URL sendiri dan teks CTA dapat disesuaikan.

Apakah produk dummy bisa dihapus?

Bisa. Produk dummy adalah data biasa dan dapat diedit, dipublish/draft, atau dihapus dari dashboard.

Boleh membuat repository public?

Secara teknis bisa, tetapi untuk source berlisensi personal sangat disarankan menggunakan repository Private.
